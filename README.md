# ✅ My Desktop To-Do App

My first desktop application made with Python Tkinter.

### 🚀 Features
- Add new tasks easily
- Simple and clean GUI interface
- Lightweight and fast - runs on any PC
- Made with Python Tkinter

### 🛠️ Tech Stack
- Python 3
- Tkinter (GUI)

### ▶️ How to Run
1. Download `to_do.py`
2. Run command: `python to_do.py`
